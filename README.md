### What I learned

I focused on Flexbox for this project. I feel like I still have things to learn when using Flexbox, but I was able to finish this project. One of my biggest weaknesses is the fear of missing out when it comes to the best way to learn CSS. When I struggle a little bit with using Flexbox, I easily fall into thinking, "I'm not good enough. I didn't learn Flexbox. I need to use a different resource to learn it right this time." There is value in studying different resources, and I learned a lot by reading through web.dev. However, I felt I would have benefited more from spending that time working on the project. The best thing for me would be to work on projects and look up things I don't know as I go. In the future, I'd also like to tutor other people to gain a different perspective on learning CSS. I should believe in myself a little more, but it's easy for me to doubt myself.

One thing I was happy with was turning the text presets from the Figma design file into CSS classes and applying them to the appropriate elements. This might seem obvious if you have access to the design file, but I didn't have a Pro account before this project. Now I'm going to think more about how components are styled and which styles are used over and over again, such as font styles. I think doing things this way will help make the code easier to read. It's a step in the right direction for me. Here's a code snippet of what I'm talking about.

```html
  <h1 class="name textPreset1">Jessica Randall</h1>
```
```css
.textPreset1 {
    font-family: Inter, sans-serif;
    font-weight: bold;
    font-size: 1.5rem;
    line-height: 1.5;
}
```

One final thing for those who don't have Pro accounts: I don't think it's necessary to have a Pro account to get the most out of Frontend Mentor while working on the introductory module. In fact, I think it might be better not to have one, because I've heard it argued that making a page a pixel-perfect match isn't as beneficial as making it pass the eyeball test. Here's [an article on pixel perfection](https://www.joshwcomeau.com/css/pixel-perfection/) for those interested. I think working from the preview image, rather than the Figma design file, builds that type of skill. I checked the Figma design file because I thought the text in one part was gray, but ChatGPT insisted it was white. As one progresses through Frontend Mentor, I suspect knowing how to use Figma design files becomes more beneficial. Paying for Pro could be useful then, but it's not a necessity.

### Continued development

As I said earlier, I'm going to continue to define classes for text styling and apply the classes whose styles I want to use to the appropriate elements.  I'm also going to think about how I can use that for other design decisions.
